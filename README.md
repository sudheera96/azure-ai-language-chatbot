# HealthAssist – Azure AI Language Chatbot

## Overview

HealthAssist is a healthcare-focused chatbot developed in Python using a traditional rule-based approach and integrated with **Azure AI Language** through API calls.

The chatbot identifies predefined user intents and provides appropriate healthcare-related responses. Azure AI Language is additionally used to analyze the sentiment of each user message.

This project demonstrates how a traditional chatbot can be enhanced by integrating an external cloud-based AI service.

---

## Objectives

The primary objectives of this project are to:

- Develop a simple conversational healthcare chatbot.
- Implement rule-based intent recognition.
- Provide responses to multiple types of user prompts.
- Handle unknown, malformed, and unsupported inputs.
- Integrate Azure AI Language using API calls.
- Perform sentiment analysis on user messages.
- Demonstrate a basic chatbot conversation.
- Keep Azure credentials separate from the source code.

## Azure AI Language Integration

Azure AI Language sentiment analysis is integrated into HealthAssist through the Azure AI Text Analytics Python SDK.

The implementation uses:

```python
from azure.ai.textanalytics import TextAnalyticsClient
from azure.core.credentials import AzureKeyCredential
```

The chatbot sends the user's message to Azure AI Language using an API call.

Azure returns:

- Sentiment classification
- Positive confidence score
- Neutral confidence score
- Negative confidence score

The sentiment can be classified as:

```text
positive
neutral
negative
```

## System Workflow

The chatbot follows this general workflow:

```text
User Input
    ↓
Rule-Based Intent Recognition
    ↓
HealthAssist Response
    ↓
Azure AI Language Sentiment Analysis
    ↓
Sentiment Classification + Confidence Scores
    ↓
Display Results
```

This approach allows the project to preserve the original rule-based chatbot while adding an external AI capability.

## Error and Malformed Input Handling

The chatbot includes an unknown-input response for messages that do not match the predefined intents.

For example:

```text
User: xyz123
```

The chatbot does not crash. Instead, it provides an appropriate fallback response while Azure AI Language can still analyze the message.

This demonstrates basic robustness when handling unsupported user input.

## Security

Azure credentials are **not hardcoded into the chatbot source code**.

The Azure key is entered securely at runtime using Python's `getpass()` functionality.

Example:

```python
from getpass import getpass

os.environ["AZURE_LANGUAGE_KEY"] = getpass(
    "Enter your Azure AI Language key: "
)
```

The Azure API key should never be committed to GitHub or shared publicly.
